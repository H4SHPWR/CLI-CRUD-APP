# 🛠️ CLI CRUD App

A simple Command-Line Interface (CLI) application built with **Node.js** that allows users to manage a basic item list directly from the terminal.  
This project was part of my early learning process to understand JavaScript fundamentals and user interaction via the command line.

---

## 📋 Features

- ➕ Add a new item  
- 🔎 View all items    
- ✏️ Update an item  
- 🧹 Clear all items
- ❌ Delete an item 

---

## 🚀 Getting Started

1. **Clone the repository**

    ```bash
    git clone https://github.com/h4shpwr/cli-crud-app.git
    ```

2. **Navigate to the project folder**

    ```bash
    cd cli-crud-app
    ```

3. **Run the script**

    ```bash
    node index.js
    ```

---

## 🧠 About CRUD

This project implements the full CRUD cycle:

- **Create** — Add new items to the list  
- **Read** — View the list of items  
- **Update** — Modify existing items  
- **Delete** — Remove items individually or clear all
